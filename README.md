# テストキーパー / Test Keeper

Google Play のクローズドテストで、他の人のアプリを入れて互いにテストするとき、「毎日ちゃんと開けているか」を見守る Android アプリです。

Watches that you really open the apps you are closed-testing for others, every day (Android).

## 主な機能 / Features
- 登録したアプリごとに14日分の状況（開いた／開けなかった／今日まだ）を表示
- 開いていないアプリがあれば、毎日決めた時刻に通知で警告
- 最近入れたアプリを自動で見つけて、追加を提案
- おまかせセッション：開いていないアプリを順に出し、見て、気づいたことを声で話すだけで次へ進み、メモを残す（声も操作もないと止まります。勝手に開き続けることはありません）
- アプリ内の「新しい版を確認」→「今すぐ更新」で、最新版に上書き更新

## インストール / Install
1. [TestKeeper-latest.apk](TestKeeper-latest.apk) をダウンロードして開き、インストールします（「提供元不明のアプリ」の許可が必要です）。
2. 初回に「使用状況へのアクセス」を許可します（設定画面が開きます）。
3. 2回目からは、アプリ内の「新しい版を確認」から更新できます。

## できないこと
- アプリを勝手に開いたり、使ったことにしたりはしません。Google のテスターの規約に反するためです。このアプリは、きちんと使うための補助です。
- 記録は端末の中だけに保存します。
